
# **Messanger - Real-time Chat Application**

## **Description**
Messanger is a real-time chat application that allows users to register, log in, and start chatting with others instantly. Built using **React**, **Node.js**, and **Socket.io**, this app provides a seamless and engaging messaging experience.

## **Features**
- **User Registration**: Users can sign up with their email and password.
- **User Login**: Log in to access the chat interface.
- **Real-time Messaging**: Chat with users in real time using WebSockets (via **Socket.io**).
- **Responsive Design**: The app is fully responsive, ensuring smooth usage across devices.

## **Getting Started**

1. **Visit the website**: [Messanger App](https://shobujdasmessanger.netlify.app/)
   
2. **Register an account**:
   - Click on the **Register** button.
   - Fill in your details (email and password).
   - After submitting, you’ll be successfully registered and logged in.

3. **Log in to your account**:
   - After registering, you’ll be redirected to the **Login** page.
   - Enter your credentials to log in.

4. **Start chatting**:
   - Once logged in, you can chat with any available user in real time.
   - Type your messages in the text input box and send them.

5. **Real-time Updates**: Messages will appear instantly on your screen without needing to refresh.

## **Technologies Used**
- **Frontend**: React.js, Socket.io-client, Tailwind CSS
- **Backend**: Node.js, Express.js, Socket.io
- **Database**: In-memory storage (for simplicity)

## **Installation (For Developers)**

### **Frontend**
To set up the frontend locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/ShobujDas/Messanger
   cd messanger-frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

   The app will be running on [http://localhost:3000](http://localhost:3000).

### **Backend**
To set up the backend locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/ShobujDas/Messanger
   cd messanger-backend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

   The backend will run on [http://localhost:5000](http://localhost:5000).
